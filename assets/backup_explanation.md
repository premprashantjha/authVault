# How Local Backup Works

## Local Auto Backup

### What is it?

**Local Auto Backup** automatically saves all your 2FA accounts to an encrypted file on your device whenever you make changes.

### 🔐 Automatic Protection
- Backs up **automatically** when you add, edit, or delete accounts
- Encrypted with **your password**
- Stored **on this device only** (not in the cloud)

### 💾 What gets backed up
- All your 2FA accounts
- Favorite accounts
- App settings
- Backup timestamp

### 🔄 When to use it

**Enable Local Auto Backup when:**
- You want automatic daily protection
- You want peace of mind against accidental deletion
- You're using the same device

## Manual Backup

### What is it?

**Manual Backup** creates an encrypted backup file that you can save anywhere and transfer to other devices.

### 📤 Manual Control
- Create backup **on demand** whenever you need
- Encrypted with **your password**
- Save to **any location** (device storage, cloud services, etc.)

### 🔄 When to use it

**Use Manual Backup when:**
- Switching to a new device
- Sharing accounts with another device
- Storing backup in cloud (Dropbox, Google Drive, etc.)
- You want full control over when backups are created

## How to restore

### On the same device:
1. Go to **Settings** → **Backup & Restore**
2. Tap **"Restore from Local Backup"**
3. Enter your backup password
4. Done! Your accounts are restored

### On a new device:
Local backup cannot be transferred automatically. Instead:
1. Use **Manual Backup** to create a backup file
2. Transfer the file to your new device
3. Use **Import** to restore on the new device

## Important notes

⚠️ **Remember your password** - It cannot be recovered if lost

⚠️ **Local only** - Backup stays on this device (not synced to cloud)

⚠️ **Device transfer** - Use Manual Backup for moving to a new device

## Security

- **Password-protected** - Only you can decrypt
- **Zero-knowledge** - We never see your password or data
- **Private storage** - Other apps cannot access your backup
